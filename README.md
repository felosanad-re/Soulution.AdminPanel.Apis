# 🚀 Admin Panel - Backend API

A secure and scalable RESTful API built with ASP.NET Core for managing an Admin Dashboard system.

---

## 📌 Project Overview

This is the **backend API** for the Admin Panel system.  
It provides authentication, business logic, and database operations.

Frontend Repository:
👉 AdminPanel.front-End

---

## ⚙️ Features

- JWT Authentication
- Role-based Authorization (Admin / Super Admin)
- CRUD Operations:
  - Products
  - Users
  - Reports
- Secure API endpoints
- Global error handling
- Logging system
- Database integration

---

## 🔐 Authentication System

- JWT Token-based authentication
- Role-based access control
- Secure endpoints using authorization middleware

---

## 🗄️ Database

- SQL Server
- Entity Framework Core (Code First / Database First)

---

## 🔗 Frontend Integration

This API is consumed by the Angular Admin Dashboard.

- Frontend handles UI
- Backend handles business logic and data processing

---

## 🛠️ Tech Stack

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
- LINQ
